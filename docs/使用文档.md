## 项目介绍

这是一个完整的 React 18 示例项目，涵盖了 React 官方文档中所有常用的 Hooks、组件和 API。项目采用 Vite 作为构建工具，提供快速的开发体验。

### 主要特点

- 📦 **完整示例**：包含所有 React 内置 Hooks 的实际应用
- 🎯 **实用场景**：每个示例都基于真实的开发场景
- 📝 **中文注释**：所有代码都有详细的中文注释
- 🚀 **快速开发**：使用 Vite 实现秒级热更新
- 🎨 **美观界面**：现代化的 UI 设计

## 环境要求

在开始之前，请确保你的开发环境满足以下要求：

- **Node.js**: >= 16.0.0
- **npm**: >= 8.0.0 或 **yarn**: >= 1.22.0

检查版本命令：

```bash
node --version
npm --version
```

## 安装与运行

### 1. 克隆项目（如果从 Git 获取）

```bash
git clone <repository-url>
cd react-complete-demo
```

### 2. 安装依赖

```bash
npm install
```

或使用 yarn：

```bash
yarn install
```

### 3. 启动开发服务器

```bash
npm run dev
```

成功启动后，浏览器会自动打开 `http://localhost:3000`。

### 4. 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

### 5. 预览生产版本

```bash
npm run preview
```

### 2. TodoReducer 组件

**位置**: `src/components/TodoReducer.jsx`

**功能**: 演示 useReducer 和 useMemo 的使用

**主要特性**:
- 添加、删除、切换任务状态
- 统计任务数据（总数、已完成、未完成）
- 使用 useMemo 缓存计算结果

**Reducer 函数示例**:

```jsx
function todoReducer(state, action) {
  switch (action.type) {
    case 'add':
      return [...state, { id: Date.now(), text: action.payload, completed: false }]
    case 'toggle':
      return state.map((todo) =>
        todo.id === action.payload ? { ...todo, completed: !todo.completed } : todo
      )
    case 'delete':
      return state.filter((todo) => todo.id !== action.payload)
    default:
      return state
  }
}
```

**使用 useMemo 优化**:

```jsx
const stats = useMemo(() => {
  const completed = todos.filter((todo) => todo.completed).length
  return {
    total: todos.length,
    completed,
    pending: todos.length - completed
  }
}, [todos]) // 仅当 todos 改变时重新计算
```

## Hooks 使用指南

### 自定义 Hooks

#### 1. useLocalStorage

**位置**: `src/hooks/useLocalStorage.jsx`

**作用**: 将状态持久化到浏览器的 localStorage

**使用示例**:

```jsx
import { useLocalStorage } from './hooks/useLocalStorage.jsx'

function MyComponent() {
  const [name, setName] = useLocalStorage('username', '匿名')
  
  return (
    <input
      value={name}
      onChange={(e) => setName(e.target.value)}
    />
  )
}
```

**原理解析**:

```jsx
export function useLocalStorage(key, initialValue) {
  // 初始化：从 localStorage 读取
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = window.localStorage.getItem(key)
      return item ? JSON.parse(item) : initialValue
    } catch (error) {
      return initialValue
    }
  })

  // 同步：状态变化时写入 localStorage
  useEffect(() => {
    try {
      window.localStorage.setItem(key, JSON.stringify(storedValue))
    } catch (error) {
      console.error('写入失败:', error)
    }
  }, [key, storedValue])

  return [storedValue, setStoredValue]
}
```

1. 在 `src/components/` 目录下创建新文件
2. 编写组件代码
3. 在 `App.jsx` 中导入并使用

```jsx
// src/App.jsx
import NewComponent from './components/NewComponent.jsx'

function App() {
  return (
    <div>
      <NewComponent />
    </div>
  )
}
```

### Q2: 如何创建自定义 Hook？

1. 在 `src/hooks/` 目录下创建新文件
2. Hook 函数名必须以 `use` 开头
3. 可以使用其他 Hooks

示例：

```jsx
// src/hooks/useWindowSize.jsx
import { useState, useEffect } from 'react'

export function useWindowSize() {
  const [size, setSize] = useState({
    width: window.innerWidth,
    height: window.innerHeight
  })

  useEffect(() => {
    const handleResize = () => {
      setSize({
        width: window.innerWidth,
        height: window.innerHeight
      })
    }

    window.addEventListener('resize', handleResize)
    return () => window.removeEventListener('resize', handleResize)
  }, [])

  return size
}
```

### Q3: useState vs useReducer，何时使用？

**使用 useState**:
- 状态简单（单个值或简单对象）
- 更新逻辑简单
- 状态之间没有复杂关联

**使用 useReducer**:
- 状态复杂（多个子值的对象）
- 更新逻辑复杂（多种操作）
- 下一个状态依赖于前一个状态
- 需要在多个组件间共享状态逻辑

---

### Q4: useEffect 的清理函数何时执行？

清理函数在以下情况执行：
1. 组件卸载时
2. 依赖项改变，重新执行 effect 之前

示例：

```jsx
useEffect(() => {
  const timer = setInterval(() => {
    console.log('tick')
  }, 1000)

  // 清理函数：清除定时器
  return () => {
    clearInterval(timer)
  }
}, [])
```

### Q5: 如何优化性能？

1. **使用 useMemo 缓存计算**:

```jsx
const expensiveValue = useMemo(() => {
  return computeExpensiveValue(a, b)
}, [a, b])
```

2. **使用 useCallback 缓存函数**:

```jsx
const handleClick = useCallback(() => {
  doSomething(a, b)
}, [a, b])
```

3. **使用 React.memo 避免不必要的重渲染**:

```jsx
const MemoizedComponent = React.memo(MyComponent)
```

4. **使用 useTransition 降低更新优先级**:

```jsx
const [isPending, startTransition] = useTransition()

startTransition(() => {
  setQuery(input)
})
```

## 最佳实践

### 1. 组件设计原则

- **单一职责**: 每个组件只做一件事
- **可复用**: 提取通用逻辑到自定义 Hook
- **命名清晰**: 使用描述性的名称
- **Props 验证**: 使用 PropTypes 或 TypeScript

---

### 2. Hooks 使用规则

- **只在最顶层调用**: 不要在循环、条件或嵌套函数中调用
- **只在 React 函数中调用**: 组件或自定义 Hook

```jsx
// ❌ 错误
function MyComponent() {
  if (someCondition) {
    const [state, setState] = useState(0) // 条件调用
  }
}

// ✅ 正确
function MyComponent() {
  const [state, setState] = useState(0)
  
  if (someCondition) {
    // 使用 state
  }
}
```

---

### 3. 依赖数组最佳实践

- **准确列出所有依赖**: 包括 props、state 和函数
- **使用 ESLint 插件**: `eslint-plugin-react-hooks`
- **避免遗漏依赖**: 可能导致 bug

```jsx
// ❌ 错误：遗漏依赖
useEffect(() => {
  console.log(count)
}, []) // 应该包含 count

// ✅ 正确
useEffect(() => {
  console.log(count)
}, [count])
```

---

### 4. 状态更新最佳实践

- **使用函数式更新**: 当新状态依赖旧状态时

```jsx
// ❌ 不推荐
setCount(count + 1)

// ✅ 推荐
setCount(prevCount => prevCount + 1)
```

---

### 5. 性能优化建议

- **避免过早优化**: 先保证功能正确
- **使用 React DevTools Profiler**: 定位性能瓶颈
- **合理使用 memo**: 不是所有组件都需要
- **拆分大组件**: 减少不必要的重渲染
