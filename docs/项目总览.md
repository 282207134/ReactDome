## 🎯 项目功能概览

### 1. 状态管理组件

#### CounterCard.jsx
- **Hooks**: useState, useEffect
- **自定义 Hooks**: useLocalStorage, useTimer
- **功能**: 计数器、本地存储、计时器

#### TodoReducer.jsx
- **Hooks**: useReducer, useMemo
- **功能**: 待办事项管理、统计数据

---

### 2. 性能优化组件

#### ExpensiveCalculation.jsx
- **Hooks**: useMemo, useCallback
- **功能**: 昂贵计算缓存、函数缓存

#### TransitionSearch.jsx
- **Hooks**: useTransition, useDeferredValue
- **功能**: 搜索过滤、并发渲染

---

### 3. DOM 操作组件

#### RefDemo.jsx
- **Hooks**: useRef, useLayoutEffect
- **功能**: 聚焦元素、测量尺寸、滚动

---

### 4. 数据获取组件

#### DataFetcher.jsx
- **Hooks**: useContext, 自定义 useFetch
- **功能**: 异步数据获取、加载状态

---

### 5. 表单组件

#### FormWithId.jsx
- **Hooks**: useId, useState
- **功能**: 表单处理、可访问性

---

### 6. 全局状态管理

#### ThemeContext.jsx + ThemeSwitcher.jsx
- **API**: Context API, useContext
- **功能**: 主题切换、全局状态

## 📊 React Hooks 覆盖

### 基础 Hooks（必须掌握）

| Hook | 示例文件 | 作用 |
|------|----------|------|
| useState | CounterCard.jsx | 状态管理 |
| useEffect | CounterCard.jsx, useFetch.jsx | 副作用处理 |
| useContext | ThemeSwitcher.jsx | 跨组件状态共享 |

### 高级 Hooks（进阶掌握）

| Hook | 示例文件 | 作用 |
|------|----------|------|
| useReducer | TodoReducer.jsx | 复杂状态逻辑 |
| useCallback | ExpensiveCalculation.jsx | 缓存函数引用 |
| useMemo | TodoReducer.jsx, ExpensiveCalculation.jsx | 缓存计算结果 |
| useRef | RefDemo.jsx, useTimer.jsx | 持久化引用/DOM 操作 |

### 特殊 Hooks（按需使用）

| Hook | 示例文件 | 作用 |
|------|----------|------|
| useLayoutEffect | RefDemo.jsx | 同步执行副作用 |
| useId | FormWithId.jsx | 生成唯一 ID |
| useTransition | TransitionSearch.jsx | 标记低优先级更新 |
| useDeferredValue | TransitionSearch.jsx | 延迟更新值 |

## 📖 学习路径

### 第一阶段：入门（1-2 天）
1. 阅读 `README.md` 了解项目
2. 运行项目：`npm install && npm run dev`
3. 学习 `CounterCard.jsx`：useState + useEffect
4. 学习 `FormWithId.jsx`：表单处理

### 第二阶段：进阶（3-5 天）
1. 学习 `TodoReducer.jsx`：useReducer
2. 学习 `RefDemo.jsx`：useRef + useLayoutEffect
3. 学习 `ThemeContext.jsx`：Context API
4. 学习自定义 Hooks（hooks/ 目录）

### 第三阶段：高级（5-7 天）
1. 学习 `ExpensiveCalculation.jsx`：性能优化
2. 学习 `TransitionSearch.jsx`：并发特性
3. 阅读 `React钩子实践指南.md`
4. 自己编写自定义 Hooks

### 第四阶段：实践（持续）
1. 将学到的 Hooks 应用到自己的项目
2. 参考 `快速参考.md` 查阅语法
3. 遇到问题查阅 `API文档.md`
